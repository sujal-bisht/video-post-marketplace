# Starter music

The background tracks every edit can use with nothing set up. All of them are
public domain (CC0) from FreePD.com, the free public-domain music library run
2008-2025. FreePD has since closed; these copies come from the Internet
Archive's mirror of it (archive.org/details/freepd), taken only from FreePD's
own category folders (featured, romantic, misc, upbeat, scoring, electronic).

Public domain means: free to use in any video, commercial or not, with no
attribution, and free to ship inside this plugin.

Deliberately NOT included: anything in the mirror that is not FreePD's own
(the mirror also holds unrelated uploads), and anything named after a famous
film or TV theme, because a cover is still the original composer's work.

Re-encoded to 112 kbps AAC to keep the plugin small: the music sits about
23 dB under the voice, where the difference cannot be heard.
